This page collects Moses Boudourides's public Streamlit applications linked to his public GitHub projects. Each listed deployment was reachable when this page was prepared.

> **Scope.** The index is based on a scan of the public, non-fork repositories in the [`mboudour`](https://github.com/mboudour) GitHub account. It lists the seven repositories with Streamlit application evidence and their public deployments.

## Research methods and AI

### [AI-Assisted Systematic Reviews and Meta-Analysis](https://ai-assisted-systematic-reviews-and-meta-analysis.streamlit.app/)
A no-code companion for a three-day workshop on evidence synthesis, systematic reviews, and meta-analysis.

[Open the app](https://ai-assisted-systematic-reviews-and-meta-analysis.streamlit.app/) · [View the GitHub project](https://github.com/mboudour/ai-assisted-systematic-reviews-and-meta-analysis)

### [AI-Augmented Research](https://ai-augmented-research.streamlit.app/)
An interactive companion for an academic research seminar focused on directing, verifying, and critically assessing AI-mediated research workflows.

[Open the app](https://ai-augmented-research.streamlit.app/) · [View the GitHub project](https://github.com/mboudour/ai-augmented-research)

### [Causal Inference with Large Language Models](https://causal-inference-workshop-odxipb5ycay2fkgr9xezet.streamlit.app/)
A three-day workshop companion for causal inference with large language models, including step-by-step calculations built around U.S. Congressional speeches data.

[Open the app](https://causal-inference-workshop-odxipb5ycay2fkgr9xezet.streamlit.app/) · [View the GitHub project](https://github.com/mboudour/causal-inference-workshop)

### [Web Scraping and Data Collection](https://web-scraping-and-data-collection.streamlit.app/)
A no-code academic workshop companion for collecting, preparing, inspecting, and exporting web-based research data.

[Open the app](https://web-scraping-and-data-collection.streamlit.app/) · [View the GitHub project](https://github.com/mboudour/web-scraping-and-data-collection)

## Statistics, networks, and scientometrics

### [No-Code Statistical Inference](https://no-code-statistical-inference.streamlit.app/)
A three-day seminar companion for data, uncertainty, hypothesis testing, group comparisons, categorical inference, regression, prediction, diagnostics, and reproducibility.

[Open the app](https://no-code-statistical-inference.streamlit.app/) · [View the GitHub project](https://github.com/mboudour/no-code-statistical-inference)

### [Causal Attitude Network Models](https://can-models.streamlit.app/)
A configuration-driven workspace for Causal Attitude Network analyses, including public replication, completed worked-case, and transparent feasibility workflows.

[Open the app](https://can-models.streamlit.app/) · [View the GitHub project](https://github.com/mboudour/can-models)

### [Scientometric Source Comparison](https://comparative-bibiometric-study-of-openalex-dimenionsai.streamlit.app/)
A reproducible application for assessing how bibliographic infrastructure affects scientometric network conclusions based on OpenAlex and Dimensions data.

[Open the app](https://comparative-bibiometric-study-of-openalex-dimenionsai.streamlit.app/) · [View the GitHub project](https://github.com/mboudour/Comparative-Bibiometric-Study-of-OpenAlex-Dimenions.ai)
